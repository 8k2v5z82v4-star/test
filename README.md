# Die Präsident-Serie · Euro-Banknoten

Eine fiktive, künstlerische Euro-Banknotenserie. Jede Stückelung (5 €, 10 €,
20 €, 50 €, 100 €, 200 €, 500 €) wurde im Stil der echten Euro-Scheine neu
gestaltet und trägt das Porträt „The President".

## Nutzung
`index.html` im Browser öffnen – die Seite ist vollständig eigenständig
(keine externen Abhängigkeiten). Die Scheine werden per SVG aus einer
Datendefinition generiert; das Porträt liegt unter `assets/`.

## Hinweis
Kein gesetzliches Zahlungsmittel. Rein illustrativ.
